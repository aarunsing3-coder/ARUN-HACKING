Setup Guide

  1. Upload this file as index.html to your existing GitHub repository.
  2. Create a Supabase project and copy Project URL + anon/public key.
  3. Replace YOUR_SUPABASE_PROJECT_URL and YOUR_SUPABASE_ANON_PUBLIC_KEY in this file.
  4. Enable Email auth in Supabase; configure Google OAuth in Google Cloud and Supabase.
  5. Add your Vercel website URL to Supabase Authentication URL Configuration and redirect URLs.
  6. Create a protected profiles table and RLS policies for admin roles before using admin features.
This starter provides real Supabase email/password and Google OAuth code once configured. The admin role check expects a profiles table with id and role fields plus appropriate RLS. Tool history currently saves locally in this browser, not in the cloud.
